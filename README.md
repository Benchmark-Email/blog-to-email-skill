# blog-to-email — a free Claude skill by Benchmark Email

Turn any blog post into a "one idea" marketing email — using the exact repurposing pipeline behind Benchmark Email's *Marketing Minute*, the emails that opened at more than double the rate of our traditional digest newsletter.

**What it does:** paste a blog URL, and Claude runs our pipeline — an insight memo grounded in the source (no invented claims), a one-idea email draft that never reuses the blog title, a minimal-edit brand-rules pass, plus a social teaser line. You review and hit send. The AI never touches the button.

## Install in the Claude app (web or desktop)

Works on Free, Pro, Max, Team, and Enterprise plans.

1. Download **blog-to-email.zip** from this page.
2. In Claude, open **Settings → Capabilities → Skills** (labeled "Customize > Skills" in some versions).
3. Click **+** → **Upload a skill** and choose the zip.
4. Toggle it on. Then just paste a blog post URL into any chat and say "turn this into an email."

## Install in Claude Code

Put the folder at `~/.claude/skills/blog-to-email/SKILL.md` (available everywhere) or `.claude/skills/blog-to-email/SKILL.md` inside a project. Invoke with `/blog-to-email` or just ask.
